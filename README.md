# 🤖 ChatGPT Sentiment Analysis

## 📌 Project Overview
This project focuses on analyzing user feedback for ChatGPT. By processing a large-scale dataset, we categorize user reviews into **Positive, Negative, and Neutral** sentiments to visualize overall user satisfaction.

## 🛠️ Technologies Used
- **Python 3.14**
- **Pandas:** Data manipulation and cleaning.
- **TextBlob:** Natural Language Processing (NLP) for sentiment polarity.
- **Matplotlib & Seaborn:** Data visualization.

## 🚀 How to Run
1. Clone the repository: `git clone https://github.com/your-username/repository-name.git`
2. Install dependencies: `pip install pandas textblob matplotlib seaborn`
3. Run the Jupyter Notebook `ChatGPT_Sentiment_Analysis.ipynb`.

## 📊 Findings
The final visualization provides a clear breakdown of user sentiments, helping to identify common trends in user experience.
